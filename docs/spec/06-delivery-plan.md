Each phase is a vertical slice: backend, frontend and a click path you can run. Each ends with a review of the diff, then a commit. Screens are built with Carbon from the first phase (07-design-tokens), following the Figma exports with the seven changes in 05-ux. BOB (the LLM) arrives in P5 on purpose: the loop must already run correctly without it.

## Tests that earn their place

- Optimiser: energy balance closes; SOC and power limits hold; stage B never worsens stage A beyond ε; terminal SOC respected; gate-locked RTM positions unchanged; an action without an active config is never used. (One test module, small fixture portfolio.)
- Validator rejects each limit violation it is meant to catch.
- Configured actions: tier assignment from autonomy, auto limit and exceptions; a config that loosens a protected limit cannot be saved; expiry cancels the gated action and keeps the fallback.
- Clock: two workers never process the same block (concurrency test against Postgres).
- Simulator: same seed → same truth; BOB and baseline twins share truth.
- Replay harness (CI, 3 seeds): zero hard-limit violations.
- Extraction validator: tighten/loosen classification and quote check (no API calls; the API harness is opt-in).
